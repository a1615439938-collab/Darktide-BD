# Darktide 中文 / English BD Planner

手机优先的《Warhammer 40,000: Darktide》中英双语 BD 规划器。

## 功能 / Features
- 中文 + English 对照
- 7 个职业切换
- 天赋选择与 30 点计数
- 武器、祝福、词条、珍品记录
- 浏览器本地保存
- JSON 导入 / 导出
- 手机端适配
- PWA 基础支持

## 数据说明
当前页面用于 2026-09-29 `Depths of the Damned` 更新前的构筑规划。四个基础职业的新版天赋树存在路径重排，因此正式上线前应再与官方或 Games Lantern 的新版树核对连线。

静态网站，使用 GitHub Pages 部署。
