# Darktide 中文 / English BD Planner

面向桌面端与手机端的《Warhammer 40,000: Darktide》中英双语 BD 编辑器。当前产品方向是“快速完成一个 BD”，而不是把所有数据和控件堆在同一张长网页上。

## 当前交互 / Current UX

- **天赋 / 装备 / BD 信息** 三个独立工作区；手机端使用固定底部导航。
- **中文 / 中英 / English** 三种显示模式，默认中文。
- 多套 BD 本地保存：新建、复制、切换、删除、自动保存；不再要求手动点击“保存”。
- 天赋点同时显示已用点数和剩余点数。
- 锁定天赋会解释为什么不可选，并显示连接到该节点所需的路径和点数。
- 低频的来源、术语等信息默认收进“更多信息”，避免详情卡过载。
- 近战 / 远程武器采用连续编辑流程：**武器 → 祝福 1 → 祝福 2 → 词条 1 → 词条 2**。
- 武器选择支持搜索、推荐、最近使用和武器类别筛选。
- 祝福列表只显示当前武器合法祝福，并在列表中直接展示效果与等级信息。
- 配装页显示整体完成度，以及近战、远程和各珍品的完成状态。
- 珍品支持“复制上一件”和“复制到全部”；手机端珍品 2 / 3 默认折叠，外观项默认收起。
- JSON 导入 / 导出与分享链接。
- PWA 基础支持。

## 天赋树 / Talent tree

- 7 个职业切换。
- 正式服 / `Depths of the Damned` 预览树切换。
- 可视化节点、连线、30 点预算与互斥节点处理。
- 桌面端：悬停详情、左键选择 / 取消、右键取消、撤销、缩放、适配视图。
- 手机端：点击先预览，再通过详情卡明确选择；拖动树时避免误触节点。

## 数据说明

当前页面用于 2026-09-29 `Depths of the Damned` 更新前后的构筑规划。四个基础职业的未来树来自预览期数据；正式更新上线后仍需逐职业核对最终节点位置、连线、名称、数值与描述。

## 图标加载

天赋图标按职业拆包：
- 当前职业立即高优先级加载；
- 其余职业在浏览器空闲时后台预加载；
- Data Saver / 极慢网络下避免强制后台预加载。

不要恢复成首屏同步加载整个大型 `tree-icons.js`。

## 翻译原则

- 武器优先使用游戏官方简体中文译名；
- 祝福、词条、珍品继续逐项核对官方简中；
- 天赋名称与说明需区分官方资料、社区维护翻译和人工补译；
- 无法可靠确认时，不把机器翻译或临时译法冒充官方译名。


## 自动化政策

- 本仓库禁止 GitHub Actions 的 `schedule:` / `cron:` 定时任务。
- 本仓库也**禁止在其他平台自动运行**，包括 Cloudflare、Supabase、Vercel、Netlify、外部 CI/CD、服务器 cron、Webhook Runner、轮询服务等。
- 不得把定时刷新、后台任务、自动部署或其他自动执行迁移到外部平台来规避 GitHub Actions 额度。
- 外部平台如需用于本仓库，只能由用户明确手动触发一次性任务；建立任何自动执行机制前必须得到用户新的明确指令。
- 详细长期规则见 [AGENTS.md](./AGENTS.md) 与 [HANDOFF.md](./HANDOFF.md)。
